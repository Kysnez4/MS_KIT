# Не работает? Быстрые решения

Папка игры на телефоне: `/sdcard/MelonLoader/com.vkslrzm.Zombix/`

## Правильное расположение файлов

```
MelonLoader/com.vkslrzm.Zombix/
├── Mods/
│   └── ModKit.dll        ← сюда (НЕ в UserData/Mods!)
└── UserData/
    └── ModKit/           ← создаётся сама
```

## Частые проблемы

| Что вижу | Почему | Что сделать |
|---|---|---|
| В меню нет значка гаечного ключа (кнопки «Моды») | `ModKit.dll` лежит в `UserData/Mods`, а не в `Mods` | Перенесите `ModKit.dll` в `Mods` (рядом с `UserData`, не внутри неё), запустите игру заново |
| То же, папки нет | Не дали «Доступ ко всем файлам» | Настройки → Приложения → Zombix → Разрешения → Все файлы → разрешить |
| То же, файлы на месте | Ещё не завершился первый запуск | Дождитесь главного меню (несколько минут), закройте игру, откройте снова |
| «Error 255» при запуске игры | 1) Битое сохранение: его правили, не пересчитав контрольную сумму (читы, редакторы сейвов, старые моды). 2) Телефон сам убил процесс MelonLoader из-за энергосбережения | 1) Сбросить прогресс: Настройки → Приложения → Zombix → Хранилище → Очистить данные (**прогресс сотрётся**; сначала сохраните копию). 2) Для игры отключить экономию батареи: Настройки → Приложения → Zombix → Батарея → «Без ограничений» / отключить энергосбережение |
| Мод не появляется в списке | zip не в `Download` или `Download/ModKit` | Положите zip туда, в окне «Моды» нажмите «+» |
| «Нужна библиотека…» | Не установлена библиотека `modkit_*` | Скачайте её из релиза библиотек, поставьте через «+», затем мод |
| Мод есть, но не работает | Он выключен или отключился после сбоя | Включите карточку мода; если снова отключается — удалите мод и сообщите автору |
| Игра вылетает | Конфликт модов | Выключите все моды, включайте по одному |
| Установка APK не идёт | Запрещена установка из неизвестных источников | Разрешите; на предупреждение Play Protect — «Всё равно установить» |

## Если ничего не помогло
Пришлите файл `UserData/ModKit/modkit.log` и `UserData/ModKit/modkit.prev.log`.
