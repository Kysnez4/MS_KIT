# Очки практики классов: разбор `C_Battle_Manager.End_Battle`

Метод: дизассемблер (Python + capstone) по `libil2cpp.so` версии 612 (arm64), RVA из `dump.cs`. На телефоне ничего не запускалось, значения порогов и условий запуска проверять в игре.
Пометки: **[П]** прочитано в ассемблере, **[В]** вывод, **[Г]** догадка.

## Что нашлось

`End_Battle` (RVA 0x10b4124..0x10bac04) выдаёт практику так [П]:

1. Цикл `i = 0..23` (0x10b9100..0x10b91a0) по `Z_Database.Array_AbilityClassPractice` (статик +0x88): в список кандидатов попадает класс, у которого практика **≤ 45** (`cmp w8,#0x2d; b.gt`), то есть не «докачанный» (максимум 46, см. CLASSES.md §7.5).
2. `UnityEngine.Random.Range(0, число кандидатов)` (0x10b91c0) выбирает случайный класс из списка.
3. Практика выбранного класса растёт на 1 (0x10b9328..0x10b9338: `ldr w10,[arr+0x20+i*4]; add w10,w10,#1; str`).
4. Из `Z_Database.Game_SciencePoint` (ObscuredInt, статик +0x904, «очки науки») вычитается **100** (0x10b9340..0x10b935c: геттер ObscuredInt, `sub w0,w0,#0x64`, сеттер) [П].
5. Тот же блок повторяется ещё раз (0x10b9360..0x10b9504) — вероятно, выдача идёт до двух раз за бой [В]. Список кандидатов при этом не пересобирается заново после первого выбора [В, не проверено].
6. Между блоками рисуется окно награды: портрет выбранного класса (`SpriteList_ClassPortrait[id]`), `Obj_FieldPracticeClass`, шкала `Img_PracticeBar_Front`. Для списка выбранных классов используется `List<int>`.

## Чего нет

- Поле `C_Battle_Manager.RewardPoint_Practice` (+0xa18) и соседние `RewardLevelUp`, `SciencePointNum_Past`, `PracticePointNum_Past` (+0xa10..0xa24) в `End_Battle` и методах менеджера напрямую не читаются и не пишутся [П: поиск по смещению в диапазоне методов класса дал пусто]. Перехватывать «награду практики» через это поле нельзя.
- Условие, **при котором** блок выдачи практики вообще запускается (порог очков науки?), не найдено: `Game_SciencePoint` (+0x904) в `End_Battle` встречается только как вычитание 100 в этих блоках [П]. Скорее всего, условие стоит на ветке до 0x10b9100 или считается из `Game_SciencePointCost` (+0x914) / очков за время [Г].
- Где копятся очки науки в бою (сколько за убийства, сколько за время) в этом разборе не искали.

## Как сделать «практику в зависимости от времени боя»

Рабочие точки перехвата (ничего не проверено на устройстве):

- **A. Через очки науки (проще всего).** `ctx.Before("C_Battle_Manager","End_Battle",0, …)`: пересчитать `Game_SciencePoint` из `Game_SurvivalTime` (например `floor(t / 300) * 100`), чтобы игра сама выдала нужное число практик своим кодом. Риск: ObscuredInt (писать через обёртку, а не по смещению); число выдач за бой ограничено кодом (до двух) [В].
- **B. Прямая запись.** `ctx.After("C_Battle_Manager","End_Battle",0, …)`: самим добавить практику выбранным классам в `Array_AbilityClassPractice` (индексы 0..23, максимум 46) и не трогать `Game_SciencePoint`. Окно награды игры при этом не покажет изменения, если сделать после него [В].
- **C. Replace.** Заменить выбор класса (`Random.Range`) не получится: вызов внутри метода, а хуки в середине функции недоступны (MELONLOADER.md, ограничение Harmony).

Чего не хватает для чистого решения — события `rewardPractice` с возможностью заменить значение в API ядра (план: ROADMAP.md / API_WISHLIST.md).

## Почему практика выдаётся только за первое прохождение [П]

Блок выдачи практики лежит внутри ветки «новый журнал» (AREAS.md §«Конец боя»): `Battle_ClearON == 1` (выжили нужное время зоны) и `Array_JournalProgress[j] == 0` для журнала этой зоны. После первого прохождения журнал уже `1`, ветка пропускается, практика не выдаётся. Править `Array_JournalProgress` нельзя (сохраняемый массив с контрольной суммой, повторно выдавались бы и журнальные самоцветы).

## Мод `class_practice` (melon/mods/class_practice, версия 1.0)

Решение варианта B: перед `End_Battle` запоминает практику и `Game_SurvivalTime` (`GetDecrypted()`), после — считает `min(limit, floor(время / (minutes×60)))` очков, вычитает выданное игрой и добавляет остаток случайным классам 1..24 с практикой < 46. Настройки: минут на очко (по умолчанию 5), максимум очков за бой (2). Окно награды игры очки мода не показывает; сохранение произойдёт при следующем автосохранении игры. Не проверено на устройстве.
