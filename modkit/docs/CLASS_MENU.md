# Мод class_menu (версия 4.1): что сделано

Мод `modkit/melon/mods/class_menu`: карта классов вместо родного экрана и классы мода, которые заменяют класс игры. Всё ниже проверено на устройстве (Zombim), кроме пункта «Не проверено».

## Что получилось

1. **Плотная карта классов.** Шаг сетки 120×165 при плитке 110: зазор между плитками ~10 px, под плиткой место для подписи.
2. **Выбор одним нажатием.** Нажатие на класс игры пишет `A_MainMenuInformation.SelectClassID`; на класс мода — выбирает его (повторное нажатие снимает).
3. **Кнопка «В бой».** Закрывает карту и окна ModKit (`ModKitWindow`, `ModKitDialog`, `ModKitPicker`), скрывает `Obj_FieldClass` и вызывает `Button_FieldArea_IN()` — родной экран зон со стрелками и «Войти в зону». Своего выбора зоны нет: используется родной.
4. **Класс мода заменяет класс игры.** В строке таблицы `Class` выбранного класса игры подменяются:
   - `효과ID_01..06` и `효과ID_01..06값` — эффекты класса мода (максимум 6, остальные `1`/`0`);
   - `효과 설명줄01..06`, `설명줄01..06 색깔`, `효과 설명줄 개수` — описание (подпись, текст, строки «эффект ID: значение»);
   - `이름` — название.

   Подмена делается при выборе класса и перед `Button_AreaStart`, `Button_AreaStart_Loop`, `Button_AreaSpecialSheet_Start`. Откат — после `MainMenuInformation` (возврат в меню) и при выключении мода; карта перед открытием тоже откатывает строку, чтобы показать настоящие имена.
5. Описание в родном экране классов меняется, эффекты применяются в бою (проверено пользователем).

## Почему именно подмена строки

- `Start_Ability` один раз кладёт `90000 + Game_BattleClassID` в `List_AllyAbilityLearn`, затем `AbilityStatApply` считает эффекты по строке таблицы `Class`. Подстановка `Game_BattleClassID` позже ничего не меняет (CLASSES.md §7.1).
- Прежний вариант (`SetGlobalEffects`) складывал эффекты мода с классом игры и в бою не был заметен; класс героя оставался классом игры.

## Грабли

- `GameObject.Find` в этой сборке недоступен («ICall … was not resolved»): искать объекты через `FindObjectsOfType(Il2CppType.Of<Transform>())`.
- Загрузчик обновляет мод только при смене версии: поднимать `Version` в `Menu.cs` и `mod.json`.
- Окно «Моды» лежит поверх экрана игры: без его закрытия после выбора виден список модов, а экран зон под ним.

## Не проверено

- Эффекты с отрицательным ID («+уровни заклинанию N») в бою.
- Значения `효과 설명줄 개수` больше 3 (у школ игры 1 или 3).
- Эффекты слотов 7..9: у школ читаются как мастерство, мод их не использует.

## Сборка и заливка

```
cd modkit/melon/mods/class_menu && dotnet build -c Release
python modkit/melon/pack_mod.py class_menu
adb push modkit/melon/mods/class_menu.zip /sdcard/Download/ModKit/class_menu.zip
```
