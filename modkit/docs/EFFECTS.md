# ID эффектов

Эффект в таблицах (`Ability`, `Class`, `MagicCom`, `Synergy`) — пара колонок `효과ID_NN` (какой эффект) + `효과ID_NN값` (его значение). `1` и `0` в колонке ID — «пусто».
Смыслы выведены из описаний: сначала по строкам, где ID один в строке, затем сопоставлением значений с текстом (порядок ID в строке = порядок строк описания).
Файл генерируется `modkit/tools_gen_effects.py` (смыслы — в словаре `DESC` скрипта); правьте скрипт, не этот файл.

**Уверенность:** `+` подтверждено, `~` выведено из описаний, `?` догадка.

## Как читать значения

- `%` — число процентов как есть: `4=30` → Атака +30%. Для «КД −%» значение положительное, знак минус задаётся самим смыслом ID; у ID с «±» отрицательное значение = ослабление.
- `N` — количество (+1, +2…).
- `×` — множитель: значение меньше 100 → ×N (`5` → ×5), от 100 и выше → сотые (`150` → ×1,5, `666` → ×6,66, `1000` → ×10). Встречается у комбинаций и сильных трейтов (ID 851, 881, 911, 971, 991, 1006…).
- `сотые %` — значение/100 процента (`24=50` → +0,5%/с, `67=100` → 1% маны/с).
- Активные артефакты: эффект (69, 70, 72, 78, 89, 91, 92, 131, 136) хранит КД в сотых секунды (`1800` = 18 с), а ID 706 — те же секунды (`18`) для таймера.
- Отрицательные ID — не бонусы, а ссылки на способности (см. первую секцию).

Названия заклинаний (Ability.ID 1…21): 1 Магическая пуля, 2 Огненный шар, 3 Дух, 4 Спутник, 5 Ледяные иглы, 6 Щит, 7 Молния, 8 Область электротока, 9 Цунами, 10 Метеорит, 11 Маскировка, 12 Вихрь, 13 Электрический удар, 14 Армагеддон, 15 Испепеление, 16 Энергетическая пуля, 17 Метель, 18 Таинственный луч, 19 Магический круг, 20 Лавовая область, 21 Световая вспышка.
Внутри блока заклинания ID идут группами: урон → количество → размер → КД; большие ID (1000+, 851, 881, 911…) — множители комбинаций/сильных трейтов.
