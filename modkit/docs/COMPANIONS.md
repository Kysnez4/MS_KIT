# Союзники на двойниках героя (`ICompanions`)

Проверено на устройстве (`api_probe`, 2026-10-20), декомпиляция Ghidra: `Play_Doppelganger_MotionAll` 0x10674a0, `Play_Doppelganger_Motion` 0x1067238, `Play_Doppelganger_Attack` (MoveNext 0x1066764).

## Как устроен двойник игры
- У героя 9 готовых объектов `Obj_UnitDoppelganger01..09` (с `Transform_ObjUnitDoppelganger0N` и `SpriteRenderer_Doppelganger0N`); родитель — объект «1000», не герой.
- Картинка: `Play_Doppelganger_MotionAll` копирует `sprite` и `flipX` с `Motion_Unit` героя в каждый из 9 рендереров. Цвет: `Play_Doppelganger_Motion` берёт `Doppelganger_ColorR/G/B` и прозрачности `A01..A03` у героя. То есть двойник — это уменьшенная раскрашенная копия спрайта героя, как и подозревалось.
- Стрельба: `Play_Doppelganger_Attack(Transform)` — копия цикла Магической пули героя: `UnitApply_MagicBulletNum/ShotNum/TargetNum`, шанс дополнительного выстрела `MagicBulletAdditionalFireRan`. Выстрел идёт через `Bullet_Create`, где источник — переданный `Transform`.

## Снаряды двойников (важно)
Для каждого выстрела корутина бросает кубик `1..100`; если выпало не больше `UnitApply_MagicBulletRandomRan`, снаряд подменяется случайным из четырёх: `BulletID_Fireball`, `BulletID_EnergyBullet`, `BulletID_Spirit`, `BulletID_Electric` (со своим звуком). **Заклинание изучать не нужно**: берутся ID снарядов героя. Замер (RandomRan = 60, три двойника, 2 минуты): из 567 снарядов двойников разные ID: 8 (≈38%), 6, 16, 19, 2 и 1 (обычная пуля, всего 5). По умолчанию `RandomRan` у героя 0, и двойники стреляют только Магической пулей.

## API
```csharp
var c = ICompanions.Spawn(dx, dy, spellId: 2);   // один союзник — одно заклинание (2 огненный шар, 5 ледяные иглы, 7 молния…)
c.Spell = 7;  c.Offset = new Vector2(2, 0);  c.Remove();  ICompanions.Clear();
```
`spellId > 0`: свой цикл стрельбы — ближайший враг в радиусе стрельбы героя, `Bullet_Create` со снарядом `BulletID_{Имя}` героя, число снарядов `UnitApply_{Имя}Num` (не более 5), перезарядка `ISpells.Cooldown(id)` (не меньше 0,4 с). Героя учить заклинанию не нужно. `spellId = 0`: стрельба двойника игры (Магическая пуля; подмена снарядов зависит от `RandomRan`). Слоты берутся с 9-го вниз; союзник привязан к герою (сам ходить не может), смещение `Offset` каждые 50 мс.

Проверено (api_probe, 3 союзника со спеллами 2, 7, 5): снаряды ID 6, 7 и 12, около 12 выстрелов за 11 с. Уровень урона считает снаряд по статам героя.

## Режимы движения (`Mode`, `Speed`, `Leash`, `StandOff`, `GuardRadius`)
`Follow` — рядом с героем в точке `Offset`; `Guard` — кружит у героя, при угрозе (враг ближе `GuardRadius`) встаёт между героем и врагом; `Hunt` — идёт к врагу с лучшим счётом `HP / (1 + 0,15·расстояние)` в пределах `Leash` от героя и держится на `StandOff`. Поводок `Leash` ограничивает удаление от героя. Проверено на устройстве (api_probe): по пользователю всё работает.

## Не проверено
- Размер/вид двойника на экране (масштаб 0,7) и смещения — по логу видно только позиции.
- Работа вместе с собственными двойниками игры (слоты 1..N); союзники берут слоты с 9-го вниз и не трогают слоты с включённым `IsDoppelganger_P`.
- Подмена снаряда влияет не только на двойников, но и на самого героя (одна и та же характеристика).
