# Отладка и проверка мода

Проверяйте игру **по журналам и данным игры**, а не по скриншотам и слепым тапам.

## 1. Журналы (на телефоне, пакет `com.vkslrzm.Zombix`)

| Файл | Что |
|---|---|
| `/sdcard/MelonLoader/com.vkslrzm.Zombix/UserData/ModKit/modkit.log` | журнал ModKit текущего запуска: загрузка, включение модов, `ctx.Log` (`[id] …`), `ОШИБКА`, отчёт о прошлом вылете. При старте игры прошлый журнал переносится в `modkit.prev.log` (там смотреть, что было перед вылетом) |
| `/sdcard/MelonLoader/com.vkslrzm.Zombix/MelonLoader/Latest.log` | журнал MelonLoader целиком (в том числе ваши `Log`) |
| `…/UserData/ModKit/config.json` | какие моды включены и настройки |
| `…/UserData/ModKit/store/<id>.json` | `ctx.Store` мода |

```bash
adb shell cat /sdcard/MelonLoader/com.vkslrzm.Zombix/UserData/ModKit/modkit.log | tail -50
adb logcat -c && adb logcat -s Unity MelonLoader      # нативные сообщения; в Git Bash перед adb: MSYS_NO_PATHCONV=1
```
Что искать: `мод включён: <id>`, `мод не запущен: …` (нет зависимости/версия), `ОШИБКА [id] …` (исключение, пойманное `Guard`), `конфликт модов`, строку «прошлый запуск завершился аварийно» и метки `ctx.Mark`.

## 2. Приёмы
- `ctx.Log(...)` в ключевых местах, число повторов ограничивайте счётчиком (журнал растёт быстро).
- Оборачивайте колбэки в `ctx.Guard("что", …)`: ошибка не уронит игру, а появится в журнале.
- Перед рискованным нативным вызовом ставьте `ctx.Mark("что делаю")`: если игра упадёт, после перезапуска журнал покажет последнюю метку, а мод будет отключён.
- Мод `gamelog` пишет в `gamelog.txt` значения полей героя и события боя: удобно сверять числа без скриншотов.
- Мод `api_probe`/`combat_probe` — пример «зонда»: раз в несколько секунд пишет в журнал состояние API боя.
- `ctx.Screen.Name`, `Buttons()`, `Texts()` показывают, где игра и какие кнопки есть, — проверка интерфейса без картинок.

## 3. Автотест на телефоне
`modkit/tools/autotest.py` включает набор модов, запускает бой, ждёт бота `autotest` и печатает итог:
```bash
python modkit/tools/autotest.py --mods my_mod,autotest --duration 120
python modkit/tools/autotest.py --mods my_mod --expect "UnitApply_MagicBulletNum<=3" --duration 90
python modkit/tools/autotest.py --mods a,b,gamelog --bisect       # при вылете найти виновника перебором
```
Исходы: `PASS` (бот дошёл до конца, проверки прошли), `FAIL` (проверка не прошла), `CRASH` (игра упала; скрипт перезапускает игру и печатает отчёт ядра), `TIMEOUT`. Вход в бой делается тапами по главному меню; движение героя делает сам бот изнутри игры. Пакет задан константой `PKG` в начале файла (по умолчанию `com.vkslrzm.Zombix`).

## 4. Вылеты
1. Откройте `modkit.log` после перезапуска: ядро пишет «прошлый запуск завершился аварийно», последний мод и метки; мод, на чьём коде случился сбой, отключается.
2. Если игра падает на старте, ядро откатывает набор модов к последнему стабильному запуску.
3. Нашли виновника перебором: `autotest.py --bisect`.
4. Нативные падения (`SIGSEGV`, Scudo) ловятся только метками (`ctx.Mark`) и `adb logcat`.

## 5. Частые ошибки
| Симптом | Причина и решение |
|---|---|
| «не загрузилась библиотека, от которой зависит мод» при установке | не установлена библиотека `modkit_*`; поставьте её zip тем же способом, затем мод |
| `ctx.Use`: «библиотека … не включена» | нет `depends` в `mod.json` или версия не подходит |
| Мод «не запущен: нужен мод …» | зависимость не установлена или версия ниже требуемой |
| `MissingMethodException` после обновления ядра | мод собран со старым `ModKit.dll`/библиотекой: пересоберите и поднимите `version` |
| Враги/герой `null` | боя нет (`HeroPos` пуст, `InBattle` = false): все боевые вызовы возвращают `false` вне боя |
| Данные игры не меняются | правка вне `IData.WhenReady`; для новых артефактов и классов нужен перезапуск игры |
| После правки поведение не изменилось | не поднята `version`: загрузчик не заменяет мод той же версии |
| Игра сбросила прогресс | мод писал в сохраняемые массивы (практика, золото): так делать нельзя ([API.md](API.md) §9) |
| Кириллица в исходниках превратилась в «кракозябры» | правьте файлы редактором в UTF-8; PowerShell `Set-Content`/`Out-File` меняет кодировку |

## 6. Чек-лист перед публикацией
- `Version` поднята; зависимости указаны с минимальной версией.
- Мод проверен на устройстве: включение, выключение (всё откатилось), повторное включение, бой 2+ минуты, `ОШИБКА` в журнале нет.
- В архиве нет файлов игры, декомпилята и ключей; есть README (что делает, зависимости, установка, благодарности, пометка об ИИ, если использовался).
