# Баланс магии (magic_balance)

Применяет правки с сайта `modkit/tools/balance` («Экспорт» → «Скачать JSON»).

Обновить баланс:
1. Заменить `balance.json` в этой папке новым файлом с сайта.
2. Поднять `version` в `mod.json` и в `Balance.cs`.
3. `python modkit/melon/pack_mod.py magic_balance` → `modkit/melon/mods/magic_balance.zip`.

Что применяется (только отличия от текущих таблиц игры, в журнале — строка на каждую правку):
- `spells[id].lv` — эффекты уровней → слоты `Ability` 2..9. Если у заклинания слоты 4-6 пусты, слоты 2-3 — общий шаблон уровней 2..max-1: правка одного уровня меняет все.
- `spells[id].attrs` — эффекты атрибутов (строка `Ability` с ID из поля `game`).
- `combos[id]` — эффекты, имя (`name`), требования (`req`) комбинаций; `newCombos` — новые комбинации.
- `name`, `desc`, `maxLevel`, `scale`, `add` заклинания — если заданы.
- `lines` и `colors` атрибута или комбинации — строки описания (`효과 설명줄01..06`, до 6, лишние — «`») и их цвета (`#RRGGBB` → `설명줄NN 색깔`). Сайт эти поля не выгружает: после замены `balance.json` их нужно перенести из старого файла и поправить числа. Без `lines` описание остаётся игровым.

Цвета строк как в игре: `#F5F5E1` — механика, `#6EDCFF` — бонус, `#FF6464` — штраф.

Не применяется: `hero` и `pick` (калькулятор сайта). Текст уровней заклинаний обновляет `modkit_spells_data`.
